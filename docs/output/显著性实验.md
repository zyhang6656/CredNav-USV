# PPO、Hetero-PPO 与 CWVL 显著性实验

## 1. 实验口径

- 统计日期：2026-08-06。
- PPO、Hetero-PPO 与 CWVL 均包含 5 个独立训练 seed。
- 训练随机种子：0、1、2、3、4，独立重复数为 `n=5`。
- 每个训练 seed 均在 obs3、obs4、obs5、obs6 上分别评测 200 个固定回合，合计 800 回合。
- 评测采用确定性策略、`read_strict` KF cache；所有评测的 cache hit rate 均为 1.0。
- 每个指标先在每个训练 seed 内聚合，再对 5 个训练 seed 计算均值与样本标准差。
- PPO 与 CWVL 按相同训练 seed 配对比较，并按照指标的预设有利方向计算显著性。
- 每个指标分别构成一个比较 family；每个 family 仅包含一次算法比较，因此 Bonferroni 校正因子为 1。

指标方向定义如下：

- Success rate、mean return、mean minimum actual distance、successful-episode speed：数值越高越好。
- Collision rate、timeout rate、unsafe near-miss rate、successful-episode path length：数值越低越好。

## 6. CWVL 与 COLREGs-MPCC
