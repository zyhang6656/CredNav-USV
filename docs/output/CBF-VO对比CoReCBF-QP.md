# CWVL、CBF-VO 与 CoReCBF-QP：obs3–10 实验结果

本报告汇总每个障碍物密度、每种方法 200 个评估回合的性能与 COLREGs 事件结果。

## 结论

- obs3–10 合并成功率：CWVL **83.63%**，CBF-VO **88.00%**，CoReCBF-QP **93.63%**。
- COLREGs 事件遵守率：CWVL **48.98%**，CBF-VO **50.19%**，CoReCBF-QP **52.26%**。CoReCBF-QP 相对 CWVL 提升 **3.28 个百分点**。
- obs3–10 加权在线单步控制总延迟为 CWVL **1.190**、CBF-VO **2.897** 和 CoReCBF-QP **3.362 ms/step**。

各指标表列出 obs3–10 的单密度结果，并汇总 obs3–6、obs6–10 和 obs3–10。
