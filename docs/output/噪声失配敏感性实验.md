# 噪声失配敏感性实验

## 1. 实验目的

本实验用于检验 Credibility-Weighted Value Learning（CWVL）在不同状态估计失配强度下的推理稳定性，并与 PPO 和 Hetero-PPO 进行对比。实验同时改变观测噪声协方差倍率和测量延迟，考察 CWVL 的性能优势是否仅依赖于单一的 `100R + 20-step delay` 设置。

## 2. 实验设置

- 评估场景：`obs6`，即包含 6 个动态障碍物的场景。
- 对比方法：PPO、Hetero-PPO 和 CWVL。
- 训练种子：每种方法使用 5 个独立训练种子。
- 推理回合：每个方法、每个训练种子、每个噪声条件评估 200 回合，即每种方法在每个条件下共评估 1,000 回合。
- 总评估规模：13 个噪声条件、3 种方法，共 39,000 个推理回合。
- 协方差倍率：`1R`、`25R`、`100R` 和 `400R`。
- 测量延迟：0、10 和 20 steps。
- 失配持续时间：30 steps。
- 注入时刻：主网格使用基于路径进度的候选时刻；另设 `100R + 20-step delay` 随机注入时刻对照条件。
- 配对原则：不同方法使用相同的评估地图、随机种子和共享失配轨迹。
- 报告指标：成功率，表中数值为 5 个训练种子的均值 ± 标准差。

## 4. 主要结果

1. CWVL 在全部 13 个噪声配置中的平均成功率均为三种方法中最高，平均性能排序始终为 CWVL、Hetero-PPO、PPO。
2. 相对于每个条件下表现较好的基线方法，CWVL 的平均成功率领先 5.6–6.4 个百分点。
3. 在无额外失配的 `1R + 0-step delay` 条件下，CWVL 的平均成功率为 87.5%，高于 Hetero-PPO 的 81.4% 和 PPO 的 77.0%。
4. 在原始 `100R + 20-step delay` 条件下，CWVL 的平均成功率为 86.7%，高于 Hetero-PPO 的 80.4% 和 PPO 的 77.3%。
5. 在更强的 `400R + 20-step delay` 条件下，CWVL 仍达到 86.7%，高于 Hetero-PPO 的 80.3% 和 PPO 的 76.9%。
6. 将 `100R + 20-step delay` 的注入时刻改为独立随机时刻后，CWVL 的平均成功率为 86.8%，仍高于 Hetero-PPO 的 80.4% 和 PPO 的 76.6%。
7. CWVL 在全部条件下的平均成功率范围为 86.4%–87.5%，最大变化为 1.1 个百分点，表明其推理性能在本实验覆盖的失配强度范围内保持稳定。

## 5. 结论

敏感性实验表明，CWVL 的平均推理性能优势并不局限于单一的 `100R + 20-step delay` 配置。随着协方差倍率从 `1R` 增加到 `400R`、测量延迟从 0 增加到 20 steps，CWVL 在所有测试条件下均保持最高的平均成功率；在随机失配注入时刻下，这一排序同样保持不变。该结果为 CWVL 在不同噪声失配强度下的稳定性提供了系统性证据。
